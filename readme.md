# Brain Tumor Classification using Machine Learning

## 📌 Project Overview

This project focuses on the detection and classification of brain tumors using MRI (Magnetic Resonance Imaging) scans. The goal was to build a robust model that can automatically distinguish between different types of tumors, aiding in early diagnosis and more efficient medical screening.

## 🛠️ Technical Stack

- **Language:** Python
- **Core Libraries:** TensorFlow/Keras, OpenCV, Scikit-learn
- **Visualization:** Matplotlib, Seaborn
- **Data Processing:** NumPy, Pandas

## 🔍 The Dataset & Methodology

The project utilizes a dataset of brain MRI scans categorized into four classes:

1. **Glioma Tumor**
2. **Meningioma Tumor**
3. **Pituitary Tumor**
4. **No Tumor** (Healthy)

### Key Project Phases:

- **Image Preprocessing:** Resizing, normalizing pixel values, and data augmentation to improve model generalization.
- **Feature Extraction:** Identifying patterns within the MRI scans using Convolutional Neural Networks (CNN) or traditional ML feature engineering.
- **Model Training:** Implementing and comparing models like **SVM**, **Random Forest**, or **Deep Learning architectures** to achieve high accuracy.
- **Evaluation:** Assessing performance through confusion matrices, precision-recall curves, and accuracy metrics.

## 📂 Repository Structure

- `Major Project Presentation Sumanth Soora.pptx`: Detailed presentation explaining the clinical significance and technical results of the project.

## 🚀 Impact

By automating the classification of tumor types, this project demonstrates how machine learning can serve as a supportive tool for radiologists, reducing the time required for manual scan reviews.
